# LowVRAM Lab

**Running quantized image and video generation workflows on a constrained NVIDIA T4 GPU using Google Colab and ComfyUI.**

LowVRAM Lab is a practical engineering project exploring how quantized generative models can be run within limited GPU memory. It brings together text-to-image generation, image-to-video generation, staged model loading, memory-aware decoding, and optional video frame interpolation.

> **Status:** Experimental workflows. The results below describe specific Colab runs; performance, compatibility, and moderation behavior can vary with model revisions, custom nodes, and runtime availability.

## Demonstration

The example workflow has three stages:

1. Generate a source image with Qwen-Image 2.1.
2. Animate the image with MiniMax H3.
3. Optionally apply RIFE frame interpolation to the generated video.

|---|---|---|

## Memory and performance notes

The notebooks use quantized weights and staged model loading to make constrained-GPU experiments possible. These techniques do not imply that every component fits in VRAM simultaneously, nor that quantized output quality matches full-precision inference.

Peak VRAM should be measured during a fresh run with a sampling monitor such as `nvidia-smi`. Do not estimate peak VRAM by adding model-file sizes: files can be loaded at different stages, and runtime allocations include additional buffers and workspaces.

## Safety and limitations

The notebooks implement **best-effort moderation**, not guaranteed safe generation.

- **Prompt screening:** keyword-based checks block some prompts but can miss paraphrases and may reject benign content.
- **Input image moderation:** an image classifier checks the uploaded reference or opening image.
- **Generated image moderation:** the Qwen workflow checks the generated image against a configured classifier threshold.
- **Generated video moderation:** the MiniMax workflow is designed to apply an image classifier to decoded video frames. If only sampled frames are checked, content between samples may be missed.
- **Output handling:** do not claim that flagged files are always removed until all ComfyUI save locations, temporary files, and downloaded copies have been tested.

The Qwen output recorded a classifier score of `0.000` against a threshold of `0.85`. This describes that one scan only. Classifiers can produce false positives (for example, benign swimwear or beach scenes) and false negatives. The supplied run log does not establish that the final RIFE video passed a complete frame-by-frame moderation scan.

Before describing video moderation as fail-closed, test benign media, policy-compliant disallowed test cases, unreadable video, classifier errors, and failed scans. Confirm that unapproved media is not placed in the approved output directory.

## Reproduce the workflows

1. Open the relevant notebook in Google Colab.
2. Select a compatible GPU runtime; the recorded runs used an NVIDIA Tesla T4.
3. Run cells in order from a fresh runtime.
4. Review the licenses and usage terms for each model, adapter, and custom node before downloading or using it.
5. Set the prompt, seed, resolution, sampler, and other parameters.
6. Save the full run log and record output metadata, elapsed time, and peak-memory measurements where available.
7. Review generated media before publishing it.

Colab GPU availability, model downloads, dependency versions, and custom-node behavior can change. A previous successful run does not guarantee an identical future run.
